Key Features

Fast Analysis

Instant analysis of entropy and file format signatures. No waiting for indexing.

Multi-Format

Full support for PE, ELF, and Mach-O binaries on all major architectures.

String Extraction

Efficiently extracts ASCII strings with smart filtering and deduplication.

Disassembly

Built-in disassembly for .text sections via the Capstone engine.

Packer Detection

Identifies packers like UPX and obfuscators like Garble or ConfuserEx.

Zero Dependency

Single statically-linked binary. No need for Python, Node, or Java.

Installation

Windows (PowerShell)

Copied! iwr -useb https://github.com/Kleshzz/binpeek/releases/latest/download/binpeek-windows-x64.exe -OutFile binpeek.exe

Linux / macOS (Bash)

Copied! curl -L https://github.com/Kleshzz/binpeek/releases/latest/download/binpeek-linux-x64 -o binpeek && chmod +x binpeek

Via Cargo (All platforms)

Copied! cargo install binpeek

Quick Usage

Windows

Copied! .\binpeek.exe target.exe

Linux / macOS

Copied! ./binpeek target.bin

Use keys 1-5 to switch tabs and Arrow keys for scrolling.
